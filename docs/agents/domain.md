# Domain Docs

This is a single-context repo for agent-skill purposes.

Before architecture, diagnosis, or implementation planning, read:

- `CONTEXT.md` for domain language and module ownership rules
- `docs/adr/` for architectural decisions relevant to the area being changed
- `AGENTS.md` for implementation rules and codebase conventions

Use the vocabulary from `CONTEXT.md` when naming modules, issues, tests, and refactor proposals.

If a proposed change contradicts an ADR, call that out explicitly before making the change.
